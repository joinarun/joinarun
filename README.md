## Selected public projects

### [AccessPilot](https://github.com/joinarun/accesspilot)

An accessibility auditing and repair prototype that connects rendered findings to source changes, checks supported fixes, and pauses for human review before publication. Demonstrates agent orchestration, browser automation, and conservative repair workflows.

**Python · Google ADK · FastAPI · React · TypeScript · Playwright · axe-core**  
[Recorded demo](https://www.youtube.com/watch?v=khPh1yecPDA) · [Architecture and limitations](https://github.com/joinarun/accesspilot/tree/main/docs)

### [RoleCallAI](https://github.com/joinarun/RoleCallAI)

A voice-first meeting facilitator with a deterministic controller for speaker turns, microphone permissions, and meeting time. Combines live AI facilitation with document retrieval, captions, and recaps. The hackathon application has documented access and deployment limits.

**Python · Google ADK · Gemini Live · LiveKit · React · Terraform · Google Cloud**  
[Recorded demo](https://youtu.be/lUjKNMtc42U) · [Architecture](https://github.com/joinarun/RoleCallAI/blob/main/docs/ARCHITECTURE.md)

### [ChangeOrder](https://github.com/joinarun/ChangeOrder)

Compares a project brief with client requests, cites the evidence for scope decisions, and turns human-reviewed additional work into a client-approved PayPal sandbox invoice. Demonstrates full-stack workflow design and explicit approval and payment states.

**TypeScript · React · Express · SQLite · AG Grid · PayPal sandbox**  
[Interactive browser sample](https://joinarun.github.io/ChangeOrder/) — prewritten findings and local storage; no live AI or payment calls.

### [VirtualWardrobe](https://github.com/joinarun/VirtualWardrobe)

A saree-focused discovery and AI try-on application with customer and staff interfaces. Demonstrates a Java backend connected to a modern web frontend, with specifications and deployment evidence. Mobile clients are planned; human saree-fidelity evaluation remains pending.

**Java · Spring Boot · React · TypeScript · Google Cloud**  
[Setup and product documentation](https://github.com/joinarun/VirtualWardrobe#readme)
